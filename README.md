# Isolation Forest Anomaly Detection

## Deskripsi

Repository ini merupakan implementasi metode **Isolation Forest** untuk mendeteksi anomali pada transaksi keuangan menggunakan dashboard interaktif berbasis Streamlit.

**IMPLEMENTASI METODE ISOLATION FOREST UNTUK DETEKSI ANOMALI PADA TRANSAKSI KEUANGAN BERBASIS DASHBOARD INTERAKTIF**

---

284.807 transaksi
